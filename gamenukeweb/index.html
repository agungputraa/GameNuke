    Technical Architecture

    Connection Engine Priority Stack

    Game Nuke's unified connection manager automatically routes every privileged command through the best available backend in priority order.

    01
    iADB Bridge
    Highest priority — lightweight privileged binder
    • ✓ Persistent Unix abstract socket — survives WiFi-off
    • ✓ Zero ADB transport overhead after initial setup
    • ✓ ContentProvider auto-delivers binder on app start
    02
    Shizuku API
    Second priority — industry-standard privileged API
    • ✓ ShizukuProvider delivers binder automatically on startup
    • ✓ Persists across app kills and WiFi state changes
    • ✓ Supports Android 11+ Wireless Debugging
    03
    Local Unix Daemon
    Third priority — persistent background shell
    • ✓ Abstract socket IPC — no file system dependency
    • ✓ 60-second watchdog heartbeat for reliability
    • ✓ Base64-encoded command protocol for safety
    04
    Wireless ADB (Native)
    Fallback — session-based transport
    • ✓ mDNS discovery with mDNS TTL-based endpoint caching
    • ✓ libadb-based shell transport (stdin script mode)
    • ✓ Self-healing reconnect on network availability signal
    // NukeConnectionManager — unified command dispatch fun executeCommand(cmd: String): Result = when (activeBackend()) { IADB -> NukeIadbBridge.execute(cmd) SHIZUKU -> NukeShizukuBridge.execute(cmd) DAEMON -> NukeDaemonClient.execute(cmd) ADB_NATIVE -> AdbManager.executeCommandDirect(cmd) NONE -> null // monitoring-only mode }

    System Requirements

    Compatibility & Prerequisites

    Base Requirements Required
    • Android 11 (API 30) or higher
    • SYSTEM_ALERT_WINDOW permission
    • POST_NOTIFICATIONS permission (Android 13+)
    • NEARBY_WIFI_DEVICES for ADB discovery
    Privileged Shell Recommended
    • Shizuku v13+ (from Play Store / GitHub)
    • OR iADB companion app
    • Wireless Debugging enabled (Developer Options)
    • Enables: all shell-based features
    Macro Engine Optional
    • Accessibility Service enabled (for fallback engine)
    • Settings → Accessibility → Game Nuke Macro
    • Auto-used when Shizuku is not available
    • Compatible with all Android 11+ devices
