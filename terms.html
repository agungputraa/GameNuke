Terms of Service

Ketentuan dasar untuk penggunaan Game Nuke Official, distribusi APK, kompatibilitas perangkat, dan batasan tanggung jawab.

Using the site and application

Dengan menggunakan situs atau mengunduh Game Nuke, Anda menyetujui untuk menggunakan layanan sesuai hukum yang berlaku, kebijakan Android, ketentuan game atau aplikasi yang Anda jalankan, dan batasan perangkat Anda sendiri. Jika Anda tidak setuju dengan ketentuan ini, jangan melanjutkan penggunaan.

Software use

Game Nuke diberikan untuk penggunaan sesuai build yang didistribusikan melalui kanal resmi. Anda tidak memperoleh hak atas nama, logo, desain, source code, atau aset lain kecuali ada lisensi terpisah yang secara eksplisit menyatakan demikian.

Compatibility and feature availability

Android 11–16 adalah rentang platform yang ditargetkan pada informasi rilis saat ini, tetapi kompatibilitas penuh tidak dapat dijamin untuk setiap vendor, ROM, chipset, kernel, atau game. Beberapa fitur membutuhkan izin tambahan seperti Accessibility, Wireless Debugging, atau Shizuku. Fitur yang tidak didukung oleh perangkat dapat tidak tersedia atau memiliki perilaku berbeda.

No guaranteed performance outcome

Telemetry dan utility Game Nuke membantu pengguna memahami dan mengatur kondisi perangkat. Tidak ada jaminan bahwa penggunaan Game Nuke akan meningkatkan FPS, menurunkan latency, menghilangkan thermal throttling, memperpanjang baterai, atau menghasilkan keuntungan kompetitif tertentu. Hasil dipengaruhi oleh hardware, suhu lingkungan, konfigurasi sistem, jaringan, dan software lain yang berjalan.

Downloads and third-party destinations

Unduh build hanya dari portal resmi atau store listing yang ditautkan. Portal dapat menggunakan GitHub release infrastructure untuk file APK dan dapat memiliki partner sponsor. Tautan pihak ketiga tunduk pada syarat dan kebijakan mereka sendiri.

Acceptable use

Jangan menggunakan Game Nuke untuk tujuan yang melanggar hukum, merusak perangkat orang lain, mencoba mendapatkan akses tanpa izin, atau melanggar aturan layanan game/publisher. Pengguna bertanggung jawab mengevaluasi apakah suatu fitur sesuai dengan aturan game dan perangkat yang digunakan.

Changes to these terms

Ketentuan dapat diperbarui ketika build, distribusi, atau fungsi situs berubah. Tanggal perubahan penting dapat dicatat di release notes atau dokumentasi. Penggunaan setelah perubahan berarti Anda menerima versi terbaru dari ketentuan yang berlaku.
